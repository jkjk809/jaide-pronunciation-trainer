# Jaide Pronunciation Trainer

AI pronunciation tool that provides phonetic feedback and grading on speech input

**Live Website:** [https://jaide-pronunciation-trainer.vercel.app](https://jaide-pronunciation-trainer.vercel.app)  
**Live Backend API:** [https://froglover54-pronunciation-backend.hf.space/docs](https://froglover54-pronunciation-backend.hf.space/docs)

---

## Tech Stack

- **Frontend:** React, Vite, (CSS/Tailwind) — *Hosted on Vercel*
- **Backend:** Python, FastAPI, Docker — *Hosted on Hugging Face Spaces*
- **DevOps / CI/CD:** GitHub Actions (Automated backend directory sync to HF Space)
